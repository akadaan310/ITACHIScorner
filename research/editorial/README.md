# Private editorial scaffolds

The JSON files are empty metadata templates, not lessons or a manuscript. They contain no attributed techniques, instructional claims, exercises or chapters. The book's requested 300–400-page target remains subject to the eventual validated evidence scope.

Use the corresponding [learning-unit](../schemas/learning-unit-draft.schema.json) and [book-plan](../schemas/book-plan-draft.schema.json) schemas only in private review tooling. Record immutable evidence pack references, current finding lineage, counterexamples, uncertainty, source fidelity, qualified content/scholarly review as appropriate and separate creator authorization. Actual review decisions require authenticated staff identities and content-hash-bound decisions in the database editorial service. Template JSON cannot authorize publication.

Gate 4 remains blocked until real corpus coverage and gaps, independently replicated and falsifiable discoveries, current lineage, human assessment and creator permission are established. Public course text, a purported creator method and substantive book authoring are outside this scaffold. `publication_allowed`, `pedagogy_eligible` and attribution remain false.
