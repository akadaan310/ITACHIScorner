# Integration readiness

No livestream, TikTok comments, YouTube live-chat, automatic attendance, mentorship, billing or paid model integration is connected. The application does not host livestreams or publicly simulate these services.

## Supabase

Real SSR Auth/persistence adapters require an explicitly selected creator-scoped project, reviewed migrations, URL/publishable key, email configuration and server-only deletion credentials. Local role tests are distinct from hosted end-to-end verification. See [AUTH_PRIVACY_SETUP.md](AUTH_PRIVACY_SETUP.md). Missing configuration and provider failures never fall back to fictional data or browser demo accounts. The unrelated inactive project visible during discovery was not used or modified.

## Sources

The importer accepts an explicitly supplied metadata manifest and authorized private export directory. No compatible handoff locator was available. No downloader, logged-in scrape, transcript publication or second acquisition project is started. Inventory completeness needs a reconciled canonical listing; transcript completeness measures eligible imported tracks separately. Inaccessible/rights-pending records remain gaps. Versions, intervals and checksums travel with every evidence span.

## Identities and future adapters

Self-entered handles prove no ownership or attendance. OAuth identities require official consented provider verification and trusted server writes. In-app participation can attest only an actual in-app action with server timing, never TikTok viewing/comments. Future event/trivia features need real creator-approved records and moderation.

Any platform adapter needs documented scopes, creator authorization, consent, limits, retention and deletion. Inference needs corpus-measured costs and explicit spend approval. Payments need separate approval and real optional original services. These are future gates, not working integrations.
